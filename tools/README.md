# 游戏公式计算工具箱

一个基于浏览器的本地工具集，包含时间戳转换、JSON格式化、工作/资源计算、战斗伤害计算和标准人口查询五大功能模块。

## 使用方式

双击 `index.html` 在浏览器中打开即可使用，无需安装任何依赖，完全离线运行。

## 功能页签

### 1. 时间戳工具

- 实时显示当前时间、秒时间戳、毫秒时间戳
- 时间戳转时间：支持秒/毫秒自动识别，输出格式 `2026-08-06 17:50:00`
- 时间转时间戳：输入日期时间，同时输出秒和毫秒时间戳
- 所有结果支持一键复制

### 2. JSON格式化

- 粘贴后自动格式化，无需手动点击
- 可折叠树形视图展示（key紫色、数值蓝色、字符串绿色、布尔橙色、null灰色）
- 全部展开/折叠按钮
- JSON压缩、复制、清空功能
- 错误智能分析：自动检测缺失括号、多余逗号、单引号等问题
- 尝试自动修复并提供「应用修复」按钮
- 支持 Ctrl+Enter 快捷格式化

### 3. 工作计算

采用左右分栏布局：左侧输入属性，右侧实时展示计算结果。

**属性JSON输入：**
- 粘贴包含 `attrId` 和 `value` 的 JSON 数据后自动解析并导入属性值
- 支持 500ms 防抖自动解析，导入成功后显示绿色提示

**基础参数：**
- 工作人口（pop）、标准人口（stdPop）、工作量（workLoad）

**属性值网格（24项）：**
- 标签标注了「万分比」或「数值」类型，与 Attr.xlsx 定义一致
- 万分比属性在计算时自动除以 10000

**人口边际效应公式：**
- `pop < stdPop` 时：`popFactor = pop / stdPop`
- `pop >= stdPop` 时：`popFactor = 1 + 0.3 * ln(pop / stdPop)`

**时间计算（建造/科研/训练/治疗/事件）：**
- `time = (workLoad / ((baseEff + specEff) * totalPop * (1 + speeds))) * 3600`

**资源产出计算（木头/石头/食物/铁矿）：**
- `output = (resBase + resEff * totalPop) * (1 + resSpeedAll + resSpeedSpec)`

### 4. 伤害计算

11步战斗伤害管线，完整复刻 Excel VBA 宏逻辑，采用左右分栏布局。

**多场景对比：**
- 点击 `+` 按钮新增场景，每个场景独立保存所有参数
- 支持关闭场景、复制当前场景
- 「对比所有场景」按钮：横向对比所有场景的攻击/防御/普攻/技能/暴击值

**表达式输入：**
- 所有输入框支持表达式计算，如输入 `=1*1.2` 失焦自动计算为 `1.2`
- 支持 `+` `-` `*` `/` `(` `)` 运算符

**百分比实时显示：**
- 百分比类输入框右侧显示橙色百分比提示，如输入 `0.1606` 显示 `16.06%`

**11步计算管线：**

| 步骤 | 名称 | 公式 |
|------|------|------|
| 1 | 闪避判定 | 触发闪避则伤害归零 |
| 2 | 基础伤害 | `atk² / (atk + K * def)`，K=2.5 |
| 3 | 普攻/技能分支 | `baseDmg * (skillCoef + add - red)` |
| 4 | 暴击倍率 | `critFactor = 1 + max(critAdd - critRed, 0)` |
| 5 | 克制修正 | `*= (1 + restrainAdd) * (1 - restrainRed)` |
| 6 | 士气修正 | `*= max(atkMorale / defMorale, 1)` |
| 7 | 累加型修正 | `coef > -1: *= (1+coef)`；否则 `*= 1/(1+|coef|)` |
| 8 | 加深/减免 | `*= (1 + deepen) * (1 - reduce)` |
| 9 | 易伤修正 | `*= (1 + vulnerability)` |
| 10 | PVP/PVE修正 | `*= (1 + add - red)` |
| 11 | 指挥修正 | 攻方指挥 > 守方指挥时 `*= 1.05` |

**输入说明：** 百分比值直接输入小数（与 Excel 一致），例如 16.06% 输入 `0.1606`。

### 5. 标准人口

- 内置公式计算.xlsm 中「标准人口」子表的全部 **481 条**记录，覆盖 16 种建筑、30 级
- 拖入 `BuildingConfig.xlsx` 自动读取子表 `BuildingLevelConfig` 中的 `level`、`name`、`upgrade_workload`、`standard_population` 列
- 导入后自动过滤 `upgrade_workload` 为 0 的无效数据
- 支持搜索框、建筑筛选下拉、等级筛选下拉组合过滤
- **localStorage 持久化**：导入的数据 F5 刷新后不丢失
- 「重置为默认数据」按钮可恢复内置数据

## 技术说明

- 纯前端实现，单文件 HTML（内联 CSS + JS）
- 引入 SheetJS CDN 处理 xlsx 文件解析
- 无其他外部依赖，支持离线运行
- 兼容 Chrome、Edge、Firefox 等现代浏览器
- 计算逻辑来源于 Excel VBA 宏，已完整移植为 JavaScript
- 数据持久化使用 localStorage
