## 四维评分体系

| 维度 | 名称 | 满分 | 核心逻辑 |
|------|------|:----:|----------|
| 维度1 | 均线位置 | 8 | 股价与 MA5/MA10/MA20/MA60 的多头排列强度 |
| 维度2 | 量价信号 | 8 | 量比、换手率与涨跌幅的配合关系 |
| 维度3 | K线确认 | 8 | K线形态识别（阳线、十字星、锤子线等） |
| 维度4 | 资金方向 | 8 | 基于换手率+成交额+涨跌幅综合评估资金活跃度 |

**总分：32 分**

### 评分细则

**维度1：均线位置**

| 条件 | 得分 |
|------|:----:|
| 股价 > MA5 > MA10 > MA20 > MA60 | 8 |
| 股价 > MA5 > MA10 > MA20 | 6 |
| 股价 > MA5 > MA10 | 4 |
| 股价 > MA20 | 2 |
| 不满足以上 | 0 |

**维度2：量价信号**

| 条件 | 得分 |
|------|:----:|
| 放量突破 + 量比>2 | 8 |
| 放量上涨 + 量比>1.5 | 6 |
| 缩量回踩支撑 + 量比<0.8 | 4 |
| 量价配合正常 | 2 |
| 量价背离 | 0 |

**维度3：K线确认**

| 条件 | 得分 |
|------|:----:|
| 强势阳线吞没 + 长上影 | 8 |
| 早晨之星 / 锤子线 / 启明星 | 6 |
| 大阳线 + 实体>5% | 4 |
| 小阳线 + 下影线 | 2 |
| 无明确K线信号 | 0 |

**维度4：资金方向**

| 条件 | 得分 |
|------|:----:|
| 换手率>8% + 涨跌幅>3%（强势活跃） | 8 |
| 换手率>5% + 涨跌幅>2% | 6 |
| 换手率>3% + 涨跌幅>0 | 4 |
| 涨跌幅>0 | 2 |
| 下跌 | 0 |

### 硬性过滤条件

以下股票直接剔除，不参与评分：

1. **ST股 / \*ST股**：风险过高
2. **市值 < 30亿**：流动性不足
3. **近10日内无涨停**：默认过滤（可通过 `--no-filter` 或 `--filter-mode 1` 关闭）

## 命令行参数

```
python four_dim_scanner.py [选项]
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|:----:|------|
| `--min-score` | int | 20 | 最低入选总分 |
| `--top` | int | 50 | 最大输出数量 |
| `--output` | html/console/both | both | 输出模式 |
| `--filter-mode` | 1/2/3 | 2 | 过滤模式（见下方说明） |
| `--no-filter` | flag | - | 不过滤涨停条件（等同 `--filter-mode 1`） |

| `--cache-all` | flag | - | 批量下载全部K线到本地缓存 |
| `--cache-force` | flag | - | 强制刷新缓存（搭配 `--cache-all`） |
| `--cache-stats` | flag | - | 仅显示缓存统计信息 |

### 示例

## K线缓存机制

### 缓存策略

- 首次运行 `--cache-all` 下载全部约5000只股票K线数据到本地 `kline_cache/` 目录
- 每只股票一个JSON文件，包含最近200个交易日数据
- 后续扫描直接从本地缓存读取，**速度提升约100倍**

### 智能新鲜度判断

| 缓存状态 | 判断条件 | 行为 |
|----------|----------|------|
| 新鲜 | 今天创建 **且** 当前已收盘（15:00后） | 直接读取 |
| 盘中过期 | 今天创建 **但** 在盘中（15:00前） | 自动刷新 |
| 过期 | 非今天创建 | 自动刷新 |

### 缓存管理命令

```bash
# 批量下载（首次/补全）
python four_dim_scanner.py --cache-all

# 强制刷新全部
python four_dim_scanner.py --cache-all --cache-force

# 查看缓存统计
python four_dim_scanner.py --cache-stats
# 输出: K线缓存统计: 4962 只, 98.02 MB
#        今日新鲜(收盘后): 4962  今日盘中(待刷新): 0  过期: 0

# 守护进程（每天17:00自动刷新）
python kline_cache.py --daemon
```

## 使用场景

### 日常流程

| 时间 | 操作 |
|------|------|
| 盘后 15:30 | 运行 `--cache-all` 刷新当日K线缓存 |
| 盘后 16:00 | 运行选股器，获取候选池 |
| 晚间 | 分析候选股基本面，结合板块热度筛选 |
| 次日盘前 | 再次运行选股器，确认候选池 |
| 盘中 | 观察候选股表现，结合四维体系判断买入时机 |

### 组合使用

1. **守护进程**：`python kline_cache.py --daemon` 后台运行，每天17:00自动刷新缓存
2. **选股扫描**：`python four_dim_scanner.py` 随时运行
3. **深度分析**：对选股器筛选出的标的，进行个股深度量化分析

## 注意事项

### 技术限制

1. **数据延迟**：实时行情有3-5秒延迟
2. **API限制**：频繁调用可能触发IP封禁，建议间隔30分钟以上
3. **停牌股票**：无法获取完整数据，自动剔除
4. **缓存大小**：约5000只股票缓存约100MB，建议定期 `--cache-force` 清理异常数据

### 投资风险

1. **不构成投资建议**：本工具仅为辅助决策工具，不构成任何投资建议
2. **历史不代表未来**：四维评分基于历史数据，不能保证未来收益
3. **追高风险**：近10日有涨停的股票可能处于高位，追高风险较大
4. **市场风险**：系统性风险无法通过技术分析规避
