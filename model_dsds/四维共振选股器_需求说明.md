# 四维共振选股器 v3.0 - 需求说明文档

## 1. 项目概述

**项目名称：** 四维共振选股器（Four-Dimensional Resonance Stock Scanner）  
**版本：** v3.0  
**开发日期：** 2026-08-03  
**运行环境：** 本地 Windows + Python 3.10  

**核心目标：** 基于四维量化评分体系，从全A股中筛选出符合高胜率买入条件的标的，辅助投资者做出更理性的交易决策。

---

## 2. 四维评分体系

### 2.1 维度定义

| 维度 | 名称 | 满分 | 核心逻辑 |
|------|------|------|----------|
| 维度1 | 均线位置 | 8分 | 评估股价与MA5/MA10/MA20/MA60的关系，判断多头排列强度 |
| 维度2 | 量价信号 | 8分 | 分析成交量与价格的配合关系，识别放量突破、缩量回踩等信号 |
| 维度3 | K线确认 | 8分 | 识别关键K线形态（阳线吞没、早晨之星、锤子线等），确认反转/延续 |
| 维度4 | 资金方向 | 8分 | 跟踪主力资金净流入方向，判断资金是否持续流入 |

**总分：32分**

### 2.2 评分细则

#### 维度1：均线位置（满分8分）

| 条件 | 得分 | 说明 |
|------|------|------|
| 股价 > MA5 > MA10 > MA20 > MA60 | 8分 | 完美多头排列 |
| 股价 > MA5 > MA10 > MA20 | 6分 | 短期多头，长期均线未完全理顺 |
| 股价 > MA5 > MA10 | 4分 | 短期趋势向上 |
| 股价 > MA20 | 2分 | 中期趋势向上 |
| 其他 | 0分 | 不满足条件 |

#### 维度2：量价信号（满分8分）

| 条件 | 得分 | 说明 |
|------|------|------|
| 放量突破 + 量比>2 | 8分 | 强势放量突破关键位 |
| 放量上涨 + 量比>1.5 | 6分 | 温和放量上涨 |
| 缩量回踩支撑 + 量比<0.8 | 4分 | 缩量回踩，洗盘迹象 |
| 量价配合正常 | 2分 | 基本配合 |
| 量价背离 | 0分 | 价涨量缩或价跌量增 |

#### 维度3：K线确认（满分8分）

| 条件 | 得分 | 说明 |
|------|------|------|
| 强势阳线吞没 + 长上影 | 8分 | 极强反转信号 |
| 早晨之星 / 锤子线 / 启明星 | 6分 | 经典反转形态 |
| 大阳线 + 实体>5% | 4分 | 强势上涨 |
| 小阳线 + 下影线 | 2分 | 温和上涨 |
| 无明确K线信号 | 0分 | 无明显形态 |

#### 维度4：资金方向（满分8分）

| 条件 | 得分 | 说明 |
|------|------|------|
| 主力净流入 > 5000万 + 5日持续流入 | 8分 | 强势资金流入 |
| 主力净流入 > 2000万 | 6分 | 明显资金流入 |
| 主力净流入 > 0 + 净流入比>5% | 4分 | 温和流入 |
| 主力净流入 > 0 | 2分 | 小幅流入 |
| 主力净流出 | 0分 | 资金流出 |

### 2.3 硬性过滤条件

以下股票**直接剔除**，不参与评分：

1. **ST股 / *ST股**：风险过高
2. **市值 < 30亿**：流动性不足
3. **近10日内无涨停**：缺乏强势表现（涨跌幅≥9.5%视为涨停）

## 3. 数据源与接口

### 3.1 实时行情数据

**数据源：** 东方财富行情API  
**接口地址：** `https://push2.eastmoney.com/api/qt/clist/get`  
**请求方式：** HTTPS GET  
**关键字段映射：**

| 字段 | 含义 | 字段 | 含义 |
|------|------|------|------|
| f2 | 最新价 | f12 | 股票代码 |
| f3 | 涨跌幅 | f14 | 股票名称 |
| f5 | 成交量 | f15 | 最高价 |
| f6 | 成交额 | f16 | 最低价 |
| f7 | 振幅 | f17 | 今开 |
| f8 | 换手率 | f18 | 昨收 |
| f9 | 市盈率 | f20 | 总市值 |
| f10 | 量比 | f21 | 流通市值 |
| f23 | 市净率 | | |

### 3.2 资金流向数据

**数据源：** 东方财富资金流API  
**接口地址：** `https://push2.eastmoney.com/api/qt/clist/get`  
**关键字段：**

| 字段 | 含义 |
|------|------|
| f62 | 主力净流入 |
| f66 | 超大单净流入 |
| f72 | 大单净流入 |
| f164 | 5日主力净流入 |
| f184 | 主力净流入占比 |

### 3.3 K线历史数据

**数据源：** akshare `stock_zh_a_hist()` 函数  
**用途：** 计算均线（MA5/MA10/MA20/MA60）、RSI、K线形态识别  
**时间范围：** 最近120个交易日

## 4. 技术实现

### 4.1 依赖库

```
akshare>=1.18.0
```

> 注：v3.0 版本已将实时行情和资金流向改为直接调用东方财富API，不再依赖 akshare 的行情接口，仅保留 akshare 用于获取K线历史数据。

### 4.2 程序架构

```
four_dim_scanner.py
├── 数据获取层
│   ├── fetch_spot()          # 获取全A股实时行情（分页）
│   ├── fetch_fund_flow()     # 获取资金流向数据
│   └── calc_ma_rsi()         # 计算均线和RSI（akshare）
├── 评分层
│   ├── score_ma_position()   # 维度1：均线位置评分
│   ├── score_volume_price()  # 维度2：量价信号评分
│   ├── score_kline()         # 维度3：K线确认评分
│   └── score_fund_flow()     # 维度4：资金方向评分
├── 过滤层
│   ├── apply_filter()        # 应用硬性过滤条件
│   └── check_limit_up()      # 检测近10日涨停
└── 输出层
    ├── generate_html()       # 生成HTML报告
    └── print_console()       # 控制台输出
```

### 4.3 运行流程

```
1. 获取全A股实时行情（约5800只）
   ↓
2. 预筛选：剔除ST、市值<30亿
   ↓
3. 获取资金流向数据
   ↓
4. 对每只股票：
   a. 计算均线（MA5/MA10/MA20/MA60）
   b. 检测近10日是否有涨停
   c. 四维评分
   ↓
5. 按总分排序，输出TOP结果
```

### 4.4 命令行参数

```bash
# 默认运行（最低10分，输出HTML+控制台）
python four_dim_scanner.py

# 自定义最低分数
python four_dim_scanner.py --min-score 16

# 只输出HTML
python four_dim_scanner.py --output html

# 只输出控制台
python four_dim_scanner.py --output console

# 限制输出数量
python four_dim_scanner.py --top 20
```

## 6. 使用场景

### 6.1 日常使用

**盘前（9:00-9:30）：**
- 运行选股器，获取候选池
- 结合板块热度分析，筛选重点方向

**盘中（10:00-14:30）：**
- 观察候选股表现
- 结合四维体系判断买入时机

**盘后（15:00后）：**
- 再次运行选股器，更新候选池
- 复盘当日操作，调整策略

### 6.2 与其他工具配合

- **板块热度分析：** 先分析板块热度，再用选股器筛选板块内个股
- **个股量化分析：** 对选股器筛选出的标的，进行深度量化分析
- **话题追踪：** 追踪重点关注标的的最新动态

## 7. 注意事项与风险提示

### 7.1 技术限制

1. **数据延迟：** 实时行情有3-5秒延迟，资金流向数据可能延迟15-30分钟
2. **IP限制：** 频繁调用东方财富API可能触发IP封禁（建议间隔30分钟以上）
3. **数据缺失：** 停牌股票无法获取完整数据，会被自动剔除

### 7.2 投资风险

1. **不构成投资建议：** 本工具仅为辅助决策工具，不构成任何投资建议
2. **历史不代表未来：** 四维评分基于历史数据，不能保证未来收益
3. **追高风险：** 近10日有涨停的股票可能处于高位，追高风险较大
4. **市场风险：** 系统性风险无法通过技术分析规避

### 7.3 合规声明

> ⚠️ 本工具生成的所有内容仅供参考，不构成投资建议。股市有风险，投资需谨慎。请结合自身情况独立判断，并在必要时咨询专业投资顾问。
